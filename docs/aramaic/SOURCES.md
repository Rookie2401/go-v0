The bundled Strong excerpt is derived from the primary distributor file and has SHA-256 `9482ed4a6eb426bef87f5f20ff8b9458ed9aa253817c9ece052980ee8d6e2c76`. The selected Lexical Index excerpt has SHA-256 `2531550c5ba8a17bc3a73312ea836440eb9684bf29a853d6fdc99ee5c841f5d7`. It contains only exact source-index entries needed for augmented lemma IDs; for example `6211 b` maps to `עֲשַׂב` (“herbage”), not unaugmented Strong H6211 (“moth”). Strong H3390 (Aramaic Jerusalem) has no meaning or usage in Strong's; its 26 occurrences take the Lexical Index definition "Jerusalem". Every one of the 4,828 occurrences now has a gloss.

Licence check, 12 November 2026: the HebrewLexicon README states "These files are released under the Creative Commons Attribution 4.0 International license" and that the Strong and BDB texts remain public domain. It has no share-alike term. (A separate repository, openscriptures/strongs, distributes a JSON Strong's dictionary whose copy in the Biblia app says CC BY-SA; this build does not use it.)

Two occurrences are linked by the source to a Hebrew dictionary entry: Ezra 7:18 עֲלָךְ (lemma `5921 a`, Hebrew עַל "above") and Dan 7:19 כָּלְּהֵין (lemma 3605, Hebrew כֹּל). They are kept as the source has them and flagged `requires-review` with that reason; they are not re-pointed at the Aramaic entries (H5922, H3606). OSHB prefix lookup glosses are not represented as Strong entries. No roots or dialect paradigms are inferred.
