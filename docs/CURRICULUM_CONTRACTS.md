# Reading curriculum contracts

`src/course/curriculumPolicy.ts` derives a contract for every existing declared stage (60). The original stage purpose is the target capability, and the preceding stage purpose is the entry capability. Language-specific construction targets progress through orthography, ordinary clauses, connected narrative and discourse/register inference. Script expectations distinguish Thai segmentation/tone decoding, Devanagari orthography and contemporary Standard Albanian from historical/Gheg recognition. Genres widen into ordinary modern nonfiction as well as narrative. Length and 90–98% demonstrated coverage ranges are normative editorial targets for supported acquisition, not measured corpus statistics, verified continuity, school-grade equivalences or CEFR certification. Thai length uses adapter-segmented lexical tokens. Actual text measurements and learner history must validate these targets before continuity is asserted.

`CurriculumMetadata` records lifecycle, pedagogical role, registers, transformation provenance, named current-version native review, independent audio readiness and rejection reasons. A translation records original title, original language and translator. An adaptation has a distinct ID and points to its source; it cannot masquerade as a transcription. Existing publication and rights gates remain necessary. Generated, translated and adapted content also requires explicit current-version native review. No reviews are inferred from an editorial label. Audio publication additionally requires audio rights, review and matching content version; text availability does not imply listening readiness.

`stageAvailability` counts accessible published secular acquisition chapters and distinct works. It excludes Scripture, testimony, private/team texts, assessment material, unavailable chapters and uncleared work rights. An empty stage remains a candidate and cannot report published. This is availability evidence only: a populated stage still needs a measured transition review before a complete ladder can be claimed. Personalized coverage/readiness is advice; it must never rewrite editorial placement.

`assertPublishedStage` uses the same actual availability rules and throws a typed `StagePublicationError` with retained reasons when an editor/build attempts to declare an empty or inaccessible stage published. It has no gap waiver: unresolved exceptions remain explicit unpublished gaps, with their reasons recorded separately. Runtime path tests exercise all catalogue pages, including more than 200 chapters, and isolate private, Scripture and assessment rows from acquisition counts.

`src/course/readingAssessment.ts` provides a separate held-out reading registry contract. Before an assessment, validation requires exact identity/version, explicit assessment-use rights, documented comparability across vocabulary/syntax/length/register/genre, no prior text/work encounters and exclusion from ordinary course/recommendation sets. Keep registered IDs excluded from ordinary recommendations and encounters from initial ingestion, including preview access. Populate prior encounters from the learner store, never from an empty placeholder. Reading results preserve comprehension, gist, detail, inference, lookups, rescue use and time, with explicit editorial thresholds. They produce reading-only records, no vocabulary encounters, automatic stage promotion, listening outcomes or full B2 certification. The registry intentionally has no approved passages: rights and comparability reviews cannot be fabricated.

Integration points: attach `getStageContract(stage)` at catalogue installation; carry optional `Text.curriculum` through import/export; apply `releaseDecision` after the existing ingest publication gate; pass the real accessibility predicate and held-out IDs to `stageAvailability`; exclude assessment IDs in recommendation and ordinary encounter entry points. Persist assessment results separately and record assessment exposure so a second administration of the same work is no longer described as unseen. A later listening assessment must use its own evidence and outcomes.

Implemented runtime integration attaches contracts at catalogue installation and preserves source SHA-256/retrieval/licence/modification evidence and curriculum metadata through ingestion. Metadata changes enter the import fingerprint without changing linguistic content versions. The publication gate refuses every explicit lifecycle except ready/published, and generated/transformed wording requires an explicit native review level, date and current wording signature; legacy reviewed labels cannot substitute. A ready text becomes published metadata only after its publication gate passes. Explicit document native review is carried to version-bound curriculum review metadata; a conflicting or stale declared curriculum review blocks the imported text. Production rights filtering excludes candidate, rights-pending and rejected content independently of an owner-authored label. Rights-clear native-review drafts may remain available only for editorial preview.

`createReadingAssessmentService` uses persisted user events (including preview views), actual encounters and prior assessment attempts to validate unseen status. Registered texts require the matching `readingAssessmentId`, source rights and a real matching stage. Attempts and results persist only in AppStore meta; no ordinary encounter, mastery or placement rows are written. Starting an attempt immediately records protected exposure, so reusing the same passage is no longer unseen even if the learner abandons it. An ordinary view during the attempt invalidates its unseen result. The approved registry and ordinary recommendation provider must be supplied by the caller; the shipped registry remains empty until rights and comparability evidence is available.
