# Thai beginner review batch

This batch contains 12 original course-owned Thai draft stories, six tagged for the Grade 1 bridge queue and six for Grade 2. The topics are everyday home, food, family, school, shopping, travel and outdoor life. Vocabulary is intentionally recycled for controlled reading.

These are machine-drafted originals, not translations and not published source texts. Every document has `generated: true`, `source.authorship: generated`, `review.status: unreviewed`, `machine-drafted`, and `needs-native-review` tags. The A1/A2 placement is provisional course planning only; it is not a CEFR certification. A Thai native reviewer must check every sentence before publication. Cataloguing a draft does not approve it for learners.

Validation on 2026-10-02: 12 documents, 0 schema errors, 0 warnings; 62–89 analyzed word tokens per story (896 total analyzed tokens). All twelve have distinct content signatures and complete English sentence glosses. Unanalysed forms are retained for the native-review pass rather than silently normalized.

Files: `data/corpus/th/bridge-thai-bridge-01.json` through `bridge-thai-bridge-12.json`; work metadata is exported by `src/course/thaiBeginnerDrafts.ts` and catalogued in the Thai course. Publication gates exclude every draft from the learner library until native review.
