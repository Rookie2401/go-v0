# Biblical Aramaic in GoLearn and Ecclesia

The implementation continues GoLearn's existing Aramaic branch and normal language-pack, reader, vocabulary and FSRS infrastructure. Ecclesia is a consumer of the completed Biblical Aramaic resources, not a dependency of GoLearn.

## GoLearn

- Language identity is `arc` / `arc-bib` / `Hebr`, with RTL display and UTF-16 offsets. Hebrew knowledge is never relabelled or merged into Aramaic.
- Adapter and pack version 2 contain all 4,828 qere-path word annotations across 269 source verses. Installation remains through the existing pack installer. Source data is compiled locally; the analyser does not need a remote language service.
- `src/adapters/arc.ts` supplies indexed form analysis, ambiguity retention, exact-source context ranking, and `arcLexiconLookup` for headword/form lookup. Source provenance, glossary availability and attested examples remain explicit. No unseen morphology or roots are fabricated.
- `src/adapters/aramaic/seed.ts` and `resources.ts` are generated by `scripts/arc-build.mts` from the checked-in source snapshots. The 269 ordinary corpus documents use the existing schema, importer and Scripture-verification gate.
- `src/course/aramaic.ts` registers source readings in the existing catalogue. This inventory is not a designed learning progression. The existing recommendation and coverage contracts remain authoritative; lexical coverage is not comprehension.
- Normal GoReview pack facts consume the analyser. Ambiguity and questioned source readings can withhold unsupported exercises. Shared vocabulary projections, the six learner states, review eligibility, FSRS due dates and replay persistence remain unchanged.
- Shared OSHB decoding fixes demonstrative `Tm` without relabelling it as negative, in both Hebrew and Aramaic.

## Transfer to Ecclesia

The canonical destination is `C:/Users/CJWal/dev/ecclesia-publish`, branch `integration/github-build`. Its existing complete Aramaic text is retained. The exporter/importer add source-word IDs, raw annotation codes, segmentation, lexical evidence and the 11 source-audit warnings to the existing Aramaic token divisions. Established edition/token/lemma identities and course content are preserved. Ecclesia's word panel exposes the imported provenance and warnings; its existing GoReview Ecclesia bridge continues to own learning records and scheduling.

Use the target's `docs/ARAMAIC-GOLEARN-HANDOFF.md` for the pinned source revision, import checks, exact resource paths and Claude's course-design entry points. The handoff is in the consolidated source; the public GitHub Pages deployment is a separate publication step.

## Validation boundaries

Source fidelity is checked separately from scholarly accuracy, lexical coverage and learner comprehension. The 26 unglossed H3390 occurrences and 11 questioned annotations remain visible gaps. Targumic Aramaic and Syriac require distinct validated dialect resources and licences.
