// The Albanian reading ladder, A1 (a1-1) — authoring file (npm run sq:ladder-build turns it into data/ladder/sq/).
// Machine-drafted Standard Albanian; NOT reviewed by a native speaker. Cast as in Stage 0 (data/stage0/world.json):
// Sam (the newcomer), Ana (a nurse at the clinic), Luan (her brother, a teacher), Drita (an older neighbour who sells
// bread, Ardi's grandmother), Ardi (ten, a pupil). Also Elira and Gjergj (the children of Dritan and Mira), Dritan and
// Mira (neighbours), Ardi's grandfather in the village.
// 2026-10-08: the 72 forty-word units of the first draft (52 written here as sq-a1-1-h01 … h52 and 20 Udha / Misioni course
// texts placed in place) are joined into 17 scenes of 150–250 words, in the same order and with the same vocabulary. The
// sentences are the earlier units' own; where a course text spoke of Beni, Ana (Beni's sister) or Marku, the scene's cast
// speaks instead (Ardi, Elira, Gjergj, Sam), and sentences that said what an earlier sentence of the same scene had said were
// dropped. The 20 course texts themselves stay in data/corpus/sq; they are no longer ladder units.
// Each unit is measured by `npm run sq:ladder-author` and the gate (`npm run ladder:check -- sq`) before it stays.
// Rule of thumb that keeps the gate green: the three uses a new word needs are three unknown tokens, so a new word is
// used about three times in its own scene (twice if it is rare) and not more; a word met once or twice before is used once
// or twice; at most six or seven new words per scene.
